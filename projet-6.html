Stéganographie d'image en Python
Implémentation d'une technique de stéganographie en Python.
outils
Python
Code source
description

Implémentation d'une technique de stéganographie en Python permettant de cacher une image secrète à l'intérieur d'une image de couverture.Ce projet a permis de mettre en pratique les concepts de base de l'informatique comme les données binaires qui stokent les couleurs d'une image. Projet réalisé individuellement sur une durée de 1 mois.

Compétence
Développer des applications informatiques simples
Appréhender et construire des algorithmes
